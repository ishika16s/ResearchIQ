# 🔬 ResearchIQ
### AI Research Paper Intelligence System Using Transformers

## 📌 About the Project

ResearchIQ is an AI-powered research paper intelligence system designed to simplify the process of reading, understanding, analyzing, and exploring academic research papers.

It combines Natural Language Processing, Transformer models, semantic search, and Retrieval-Augmented Generation (RAG) to help users extract meaningful insights from research documents.

## ✨ Key Features

- **Research Paper Summarization:** Generate concise summaries of academic papers.
- **Semantic Search:** Find relevant research using meaning-based search.
- **PDF Processing:** Extract and process text from uploaded research papers.
- **Research Question Answering:** Ask questions about research documents.
- **RAG:** Retrieve relevant document content to support answers.
- **Information Extraction:** Identify objectives, methodologies, results, and conclusions.
- **Keyword Extraction:** Extract important research terms and phrases.
- **Topic Classification:** Identify research domains.
- **Paper Comparison:** Compare research papers based on important attributes.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ishika16s/ResearchIQ.git
cd ResearchIQ
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the application

```bash
streamlit run app.py
```

Note: The research notebook contains the model experiments and development workflow. The application may require additional model and index configuration before all AI features can run independently.

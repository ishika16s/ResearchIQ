# ResearchIQ
### AI Research Paper Intelligence System Using Transformers

## About the Project

ResearchIQ is an AI-powered research paper intelligence system designed to help users explore and understand academic research papers.

## Key Features

- Research paper summarization
- Semantic search
- Retrieval-Augmented Generation (RAG)
- Question answering
- Research information extraction
- Keyword extraction
- Topic classification
- Research paper comparison
- PDF text extraction

## Technology Stack

- Python
- PyTorch
- Hugging Face Transformers
- Sentence Transformers
- FAISS
- Streamlit
- PyMuPDF
- FLAN-T5
